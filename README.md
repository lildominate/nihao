# Nǐ hǎo 🇨🇳

A free, ad-free web app (PWA) for learning **spoken Mandarin** in pinyin, with a Swedish interface and no characters to learn. Duolingo-style lessons, tone training, spaced repetition and speech recognition.

- 10 units, 63 lessons, 350 words and ~400 sentences
- Listening via the phone's Chinese voice (tip: download a Premium voice on iPhone)
- Everything is stored locally on your device

## Development

```bash
npm install
npm run dev
npm test
```

Pushes to `main` are deployed automatically to GitHub Pages.
